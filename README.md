# Light simulation 

The project was created by me for the Computer Graphics 1 course in November 2025. I simulate 2 Bezier surfaces with light shining on them. There are options to change angles, surface control points, light color and its parameters, object color (or texture) and object's normal map.  

The UI is in Polish since the course was in Polish. In future i might add English version of the UI.

The project was to be done in home in two weeks and then we had 1.5 hour to implement additional functionalities (in this case it was adding second surface and spinning animation). Because of this, those parts of the project are less polished, since the priority was time and not code quality.

The project will probably not be developed further, as it's purpose is rather educational tan practical. I learned the basics of light and surface simulation so the project did its job.

## Instructions

The UI is pretty self explanatory, but there are some parameters whose name is ambiguous. Here's the meaning of them:
- kd: diffuse reflection coefficient
- ks: specular reflection coefficient
- m: specular exponent
- alfa & beta: angles of orientation of the main surface
